At PwC, I've architected real-time CDC pipelines for steel industry clients, unified heterogeneous systems into Medallion Architectures on **Microsoft Fabric**, shipped 20+ Power BI dashboards to C-suite stakeholders, and built a secure AI chatbot with **Databricks Genie Space** complete with row-level security and live query execution.
